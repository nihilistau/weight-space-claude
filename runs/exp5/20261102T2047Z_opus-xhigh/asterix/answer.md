**Design (column-5 dodger with a row-value lookahead)**

The policy never presses left or right, so the player stays in column 5 for the whole game. Every entity crosses the full row, so each one must pass column 5. Survival then reduces to choosing up, down or stay. Two facts make this tractable:

- Each row 1..8 holds at most one entity, so a row that contains gold has no enemy and is safe.
- Within a row, the trail cell shows which way the entity moves.

From that, each entity has a distance k = the number of moves until it reaches column 5. An entity that has already passed column 5 has k = ∞.

**Layer 1 (32 units)**
- **P_y, units 0..7:** the player is in row y (y = 1..8).
- **D1_r, units 8..15:** an enemy in row r is at k ≤ 1. Entering that row, or staying in it, can kill this step.
  - Score = 2·E5 + E4 + E6 + T3 + T7 − 5·(any gold in the row), firing when the score is at least 1.5.
  - A receding enemy at column 4 or 6 scores only 1, so it does not fire.
- **D2_r, units 16..23:** an enemy in row r is at k ≤ 3.
  - Enemy weights by column: E = [-1,0,0,1,2,3,2,1,0,-1].
  - Trail weights by column: T = [0,3,2,1,0,-1,0,1,2,3].
  - Threshold 2.5. Every approaching case scores 3 and every receding case scores 2 or less.
- **G_r, units 24..31:** gold in row r is approaching column 5, at any distance.
  - Gold weights: [1,1,3,3,5,5,3,3,1,1]. Trail weights: [0,-2,-2,-4,-4,-6,-4,-2,-2,0].
  - Approaching gold scores +1, receding gold −1, an empty row 0, and any enemy in the row gives a large negative.

**Layer 2 (32 units)**

Every unit is gated by P_y with weight +10 and a bias near −10. A unit is saturated at −1 unless the player is in its row. The output biases cancel the seven inactive units in each group.

- **S_y (stay):** the value of row y.
- **U_y (up):** the value of row y−1.
- **N_y (down):** the value of row y+1.
- **Row value** V = −6·[D1] − 3·[D2] + 2·[gold] + an edge penalty (−1.2 for rows 1 and 8, +0.2 for the middle rows). Staying gets an extra +0.5. The value is scaled by 1/5, so the tanh keeps the ordering deadly < risky < neutral < gold.
- **A_y (gold direction):** tanh(2·(number of gold rows above − number below)). It feeds +5 to the up logit and −5 to the down logit. This pulls the player toward far gold, but it is weaker than the safety terms.

**Output layer**
- 20 × S → no-op, 20 × U → up, 20 × N → down.
- Left, right and fire get bias −50.
